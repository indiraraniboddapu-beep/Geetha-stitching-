# Geetha Stitching Website

A modern, premium, mobile-responsive single-page website for **Geetha Stitching**, built with HTML5, CSS3, and JavaScript.

## Features
- Elegant royal maroon, gold, and cream theme
- Sticky navigation with mobile menu
- Hero, About, Services, Gallery (with category filter and lightbox), Price List, Why Choose Us, Testimonials, Booking, and Contact sections
- WhatsApp booking form integration (`+91 8499883578`)
- Floating WhatsApp and Call buttons, back-to-top button
- Scroll animations, counters, lazy-loaded images, smooth scrolling
- SEO meta tags, Open Graph tags, and LocalBusiness schema markup

## Project Structure
- [index.html](index.html) - Main single-page website
- [css/styles.css](css/styles.css) - Styles and responsive layout
- [js/script.js](js/script.js) - Interactivity and form handling
- [assets/logo.svg](assets/logo.svg) - Logo
- [assets/favicon.svg](assets/favicon.svg) - Favicon

## Run Locally
Open [index.html](index.html) in a web browser, or serve the folder with any static file server for best results.
